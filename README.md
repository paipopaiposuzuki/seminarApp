# 新しい経験ミッションアプリ（仮）

## コンセプト

時間はあるけど「何をしたらいいか分からない」大学2年生向けに、  
日常のスキマ時間でできる「価値観を広げるミッション」を提案する Web アプリ。

- 目的: 新しい経験を通して、自分の価値観を少しずつ広げることを手助けする
- 対象ユーザー: 静大浜松キャンパス周辺に住む大学2年生  
  （時間とエネルギーはあるが、具体的に何をしたいか分からない人）
- 主な利用シーン: 授業とバイトの間のスキマ時間、予定の前後、なんとなく暇な夕方 など

## コア機能（MVP）

- 今日の予定を「時間 + 場所カテゴリ（キャンパス / 浜松駅 / 自宅 など）」で入力
- 入力された予定から、スキマ時間を自動で抽出
- 各スキマ時間に対して、AI が以下をセットにしたミッションを生成
  - 行動（何をするか）
  - 視点（どんな目線で過ごすか）
  - 振り返りの問い（価値観の変化や気づきを一言で残すための質問）
- ミッションの実行ログ
  - 「やった / やってない」の記録
  - 「どれくらい“いつもと違ったか”」の簡単な評価
  - 任意の一言メモ（気づきや感想）

## 技術スタック（予定）

- フロントエンド: React
- バックエンド: Node.js（Express）
- データベース: MongoDB（MongoDB Atlas）
- 外部 API: 無料で利用可能な LLM API（ミッション生成用）
